# 🚀 Projetos Arduino

Este repositório contém códigos desenvolvidos para projetos utilizando **Arduino**.  
Os exemplos podem ser utilizados como base de estudo, aprendizado ou para criar suas próprias automações e experimentos.

## 🔧 Requisitos

- [Arduino IDE](https://www.arduino.cc/en/software) ou [PlatformIO](https://platformio.org/)
- Placa Arduino compatível (ex.: **Arduino Uno, Nano, Mega**)
- Drivers e bibliotecas necessárias (listadas em cada arquivo)

## 📂 Estrutura

- `led_e_botoes.ino` → Inicia com contagem 0, o botão da esquerda diminui a contagem em 1 e o botão da direita aumenta a contagem em 1. Caso a contagem seja divisível por 2, ascende o led vermedo. Caso a contagem seja divisível por 3, ascende o led laranja. Caso a contagem seja divisível por 5, ascende o led azul. Se a contagem for divisível por mais de uma condição, os leds correspondentes ascenderão.
